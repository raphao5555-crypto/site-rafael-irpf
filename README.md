# 🧮 Calculadora de IRPF

Calculadora de Imposto de Renda de Pessoa Física feita com **HTML, CSS e JavaScript puros**, sem frameworks ou bibliotecas externas. O projeto foi desenvolvido com foco em prática e aprendizado.

🔗 **link:** (https://raphao5555-crypto.github.io/site-rafael-irpf/)

> 🚧 **Projeto em desenvolvimento.** Novas funcionalidades e melhorias ainda estão sendo adicionadas.

## ✨ Funcionalidades

- Cálculo do IRPF com base nas faixas de tributação vigentes
- Resultado detalhado (base de cálculo, alíquota, valor do imposto)
- Layout responsivo, adaptado para celular, tablet e desktop

## 🎯 Objetivos do projeto

Este projeto foi criado para praticar:

- **JavaScript:** manipulação do DOM, eventos, validação de entradas e lógica de cálculo
- **Modularização:** separação das funções por responsabilidade, deixando o código mais legível e fácil de manter
- **Responsividade:** CSS adaptável a diferentes tamanhos de tela
- **Git e GitHub:** commits organizados, branches e versionamento do projeto
